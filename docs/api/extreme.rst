Extreme Value Module
====================

Extreme-value analysis: Generalized Extreme Value (GEV) distribution fitting
by L-moments, return levels and return periods, block-maxima sampling, and a
Peaks-Over-Threshold (POT) workflow based on the Generalized Pareto
Distribution (GPD).
